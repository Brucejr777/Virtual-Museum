# The Meridian Archive — A Virtual Museum

A fictional virtual museum built with **React 19**, **TypeScript**, **React Router 7**, and **Vite 7**. Every route is a room; every object record is an invitation to look more closely.

## Requirements

- Node.js 20.19+, 22.13+, or 24+
- npm 10+ (or pnpm / yarn / bun)

## Getting started

```bash
npm install
npm run dev          # http://localhost:5173
